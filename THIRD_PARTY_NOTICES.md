## How the models reach a device

No model file is committed to this repository. The app downloads each model once, directly from the Hugging Face Hub, pinned to the exact revision listed below, and keeps it in the browser's cache for offline reuse. Nothing the user types or translates is ever sent anywhere — the only network requests the app makes are its own files and these one time model downloads.

## Translation runtime

- **`@huggingface/transformers` (v3.8.1, resolved by package-lock.json)** — the transformers.js library that loads and runs the models in the web worker. Apache-2.0. Bundled into `public/translator.worker.js` at build time.
- **ONNX Runtime Web** — the WebAssembly runtime files (`ort-wasm-simd-threaded.jsep.wasm` and its loader) that transformers.js depends on. MIT, © Microsoft. Copied out of the transformers package by `scripts/copy-ort.mjs` and served self hosted from `/ort/`, so the app never requests them from a CDN.
- **Bergamot translator** (the wasm build shipped by `@mkljczk/bergamot-translator` v0.4.16, resolved by package-lock.json) — Mozilla's Bergamot translator (Marian + intgemm compiled to WebAssembly; upstream `mozilla/bergamot-translator`, MPL-2.0), which runs the Firefox Translations models. Copied by `scripts/copy-bergamot.mjs` and served self hosted from `/bergamot/`, fetched only when a Bergamot route first runs, and verified against the SHA-256 pins in `src/lib/bergamot/bundles.ts` (glue `bc2fc98d8598…`, wasm `735d4d95ede0…`, 5.2 MB).

## Ported code

The IndicTrans2 preprocessing and postprocessing in `src/lib/indictrans2/processor.ts` is a TypeScript port of reference Python code, with the algorithmic structure and constants preserved:

- **IndicTransToolkit 1.1.1** (`processor.pyx` — the placeholder, normalization and transliteration pipeline) — AI4Bharat, MIT.
- **indic-nlp-library 0.92** (script normalizers, transliterator, trivial tokenizers) — Anoop Kunchukuttan, MIT.
- **sacremoses 0.2.0** (the Moses punctuation normalizer and tokenizer/detokenizer, English subset actually used) — MIT.
- **urduhack 1.1.1** (Urdu character normalization) — MIT.

The research copies of these libraries (pinned release tarballs) live under `scripts/indictrans2/` as provenance; the app ships only the port, and no upstream code is bundled verbatim.
